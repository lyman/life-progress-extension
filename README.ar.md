# تقدّم الحياة · life-progress

إضافة متصفح (صفحة علامة تبويب جديدة / نافذة منبثقة في شريط الأدوات) تُبقي شريط تقدّم حياتك أمام عينيك دائمًا.

الإعداد الافتراضي: تاريخ الميلاد **1980-02-20** · متوسط العمر المتوقع **30000 يوم** (≈ 82.1 سنة · حتى 2062-04-10) — غيّره متى شئت عبر **⚙** في الزاوية العلوية اليمنى من الصفحة.

## إضافة المتصفح (Edge / Chrome ومتصفحات Chromium الأخرى · v1.3.4)

الكود في `extension/`، وله ثلاثة مداخل:

| المدخل | ملاحظات |
|---|---|
| علامة تبويب جديدة | شريط تقدّم بملء الصفحة + مربع بحث. **لا يعمل في Vivaldi**: لا يسمح Vivaldi للإضافات بالاستحواذ على علامة التبويب الجديدة (يستخدم صفحة البداية الخاصة به) |
| النافذة المنبثقة | انقر على أيقونة شريط الأدوات لرؤية التقدّم — يعمل في جميع المتصفحات (مستخدمو Vivaldi: استخدموا هذا) |
| اختصار لوحة المفاتيح | `Alt+Shift+L` يفتح النافذة المنبثقة (يمكن تغييره من الإضافات → اختصارات لوحة المفاتيح) |

التثبيت: افتح `edge://extensions` (Chrome: `chrome://extensions`، Vivaldi: `vivaldi://extensions`) →
فعّل **وضع المطوّر** → **تحميل إضافة غير مضغوطة** → اختر مجلد `extension/`.
**بعد تحديث الكود انقر على "إعادة تحميل" في تلك الصفحة** (تغييرات manifest تتطلب دائمًا إعادة التحميل)، ثم ثبّت الأيقونة في شريط الأدوات.

- تغيير الإعدادات: **⚙** في الزاوية العلوية اليمنى من الصفحة — تاريخ الميلاد / متوسط العمر المتوقع، يُطبَّق فورًا وتشترك فيه علامة التبويب الجديدة والنافذة المنبثقة (محفوظ في `chrome.storage`، متزامن بين الأجهزة المسجّلة بالحساب نفسه)؛ القيم الافتراضية في أعلى `extension/life-core.js`
- مربع البحث: يبحث عبر محرك البحث الافتراضي للمتصفح (`chrome.search`)؛ وإذا لم تكن الواجهة متاحة (مثل فتح الصفحة كملف عادي) يعود النموذج إلى Bing — غيّر هذا الاحتياط عبر `action` في `<form>` و`name` في `<input>` داخل `extension/newtab.html`
- الوضعان الفاتح والداكن يتبعان النظام تلقائيًا
- اللغات: 19 لغة في `extension/_locales/` تتبع لغة المتصفح (مع التراجع إلى الإنجليزية عند عدم التطابق)؛ إضافة لغة = إضافة مجلد؛ تنسيق الأرقام يتبع إعدادات منطقة المتصفح؛ اللغات من اليمين إلى اليسار (مثل العربية) تعكس الواجهة تلقائيًا
- إعادة توليد الأيقونات: `python3 tools/make_icons.py` (مربع أزرق بحواف دائرية + شريط أبيض بنسبة 57%، الإخراج في `extension/icons/`)

## هيكل المشروع

```
life-progress/
├── extension/           # الإضافة نفسها (اختر هذا المجلد عند "تحميل إضافة غير مضغوطة")
│   ├── manifest.json    # ملف manifest بإصدار MV3 (إذن storage، اختصار لوحة المفاتيح)
│   ├── newtab.html/js   # علامة تبويب جديدة: شريط بملء الصفحة + بحث
│   ├── popup.html/js    # نافذة شريط الأدوات المنبثقة: شريط مدمج
│   ├── life-core.js     # المصدر الوحيد للمنطق: الإعداد الافتراضي + الحساب + قراءة/كتابة chrome.storage
│   ├── i18n.js          # نقطة الدخول msg() + استبدال النص الثابت + اتجاه RTL
│   ├── settings.js      # ⚙ لوحة الإعدادات (مشتركة بين الصفحتين، تُحقن برمجيًا)
│   ├── _locales/        # 19 حزمة لغة؛ تتبع لغة المتصفح، والتراجع إلى en
│   └── icons/           # أيقونات بجميع الأحجام (يولّدها tools/make_icons.py)
└── tools/
    └── make_icons.py    # مولّد الأيقونات (مكتبة قياسية فقط؛ عدّل PCT/BG وأعد التشغيل)
```
