# ความคืบหน้าชีวิต · life-progress

ส่วนขยายเบราว์เซอร์ (หน้าแท็บใหม่ / ป๊อปอัปบนแถบเครื่องมือ) ที่ทำให้แถบความคืบหน้าชีวิตของคุณอยู่ต่อหน้าเสมอ

ค่าเริ่มต้น: วันเดือนปีเกิด **1980-02-20** · อายุขัยที่คาดหมาย **30000 วัน** (≈ 82.1 ปี · ถึง 2062-04-10) — เปลี่ยนได้ตลอดผ่าน **⚙** มุมขวาบนของหน้า

## ส่วนขยายเบราว์เซอร์ (Edge / Chrome และเบราว์เซอร์ Chromium อื่น ๆ · v1.3.2)

โค้ดอยู่ใน `extension/` มี 3 จุดเข้าใช้งาน:

| จุดเข้าใช้งาน | หมายเหตุ |
|---|---|
| แท็บใหม่ | แถบความคืบหน้าเต็มหน้า + ช่องค้นหา **ใช้ไม่ได้กับ Vivaldi**: Vivaldi ไม่อนุญาตให้ส่วนขยายเข้าคุมแท็บใหม่ (ใช้หน้าเริ่มต้นของตัวเอง) |
| ป๊อปอัปแถบเครื่องมือ | คลิกไอคอนบนแถบเครื่องมือเพื่อดูความคืบหน้า — ใช้ได้กับทุกเบราว์เซอร์ (ผู้ใช้ Vivaldi: ใช้ตัวนี้) |
| ปุ่มลัดคีย์บอร์ด | `Alt+Shift+L` เปิดป๊อปอัป (เปลี่ยนได้ที่ ส่วนขยาย → ปุ่มลัดคีย์บอร์ด) |

ติดตั้ง: เปิด `edge://extensions` (Chrome: `chrome://extensions`, Vivaldi: `vivaldi://extensions`) →
เปิด **โหมดนักพัฒนา** → **โหลดส่วนขยายที่แตกไฟล์แล้ว** → เลือกโฟลเดอร์ `extension/`
**หลังอัปเดตโค้ด ให้คลิก "รีโหลด" ในหน้านั้น** (การแก้ manifest ต้องรีโหลดเสมอ) แล้วปักหมุดไอคอนไว้บนแถบเครื่องมือ

- แก้การตั้งค่า: **⚙** มุมขวาบนของหน้า — วันเกิด / อายุขัยที่คาดหมาย มีผลทันที ใช้ร่วมกันระหว่างแท็บใหม่และป๊อปอัป (เก็บใน `chrome.storage` ซิงก์ข้ามอุปกรณ์ที่ล็อกอินบัญชีเดียวกัน); ค่าเริ่มต้นจากโรงงานอยู่บนสุดของ `extension/life-core.js`
- ช่องค้นหา: ค้นหาด้วยเสิร์ชเอนจินเริ่มต้นของเบราว์เซอร์ (`chrome.search`); ถ้า API ใช้ไม่ได้ (เช่น เปิดหน้าเป็นไฟล์ธรรมดา) ฟอร์มจะกลับไปใช้ Bing — เปลี่ยนตัวสำรองได้ที่ `action` ของ `<form>` และ `name` ของ `<input>` ใน `extension/newtab.html`
- ธีมสว่าง/มืด สลับตามระบบอัตโนมัติ
- ภาษา: 19 ภาษาใน `extension/_locales/` ตามภาษาของเบราว์เซอร์ (ถ้าไม่ตรงจะใช้ภาษาอังกฤษ); เพิ่มภาษา = เพิ่มโฟลเดอร์; รูปแบบตัวเลขตามภูมิภาคของเบราว์เซอร์; ภาษา RTL (เช่น อาหรับ) กลับด้านเลย์เอาต์อัตโนมัติ
- สร้างไอคอนใหม่: `python3 tools/make_icons.py` (สี่เหลี่ยมมุมมนสีน้ำเงิน + แถบขาว 57% ผลลัพธ์อยู่ใน `extension/icons/`)

## โครงสร้างโปรเจกต์

```
life-progress/
├── extension/           # ตัวส่วนขยาย ("โหลดส่วนขยายที่แตกไฟล์แล้ว" ให้เลือกโฟลเดอร์นี้)
│   ├── manifest.json    # manifest MV3 (สิทธิ์ storage, ปุ่มลัด)
│   ├── newtab.html/js   # แท็บใหม่: แถบเต็มหน้า + ค้นหา
│   ├── popup.html/js    # ป๊อปอัปแถบเครื่องมือ: แถบแบบกะทัดรัด
│   ├── life-core.js     # แหล่งตรรกะเดียว: ค่าเริ่มต้น + การคำนวณ + อ่าน/เขียน chrome.storage
│   ├── i18n.js          # จุดเรียก msg() + แทนที่ข้อความคงที่ + ทิศทาง RTL
│   ├── settings.js      # ⚙ แผงตั้งค่า (ใช้ร่วมทั้งสองหน้า แบบ inject)
│   ├── _locales/        # แพ็กภาษา 19 ภาษา; ตามภาษาเบราว์เซอร์ ถ้าไม่ตรงใช้ en
│   └── icons/           # ไอคอนทุกขนาด (สร้างโดย tools/make_icons.py)
└── tools/
    └── make_icons.py    # ตัวสร้างไอคอน (ไลบรารีมาตรฐานล้วน; แก้ PCT/BG แล้วรันใหม่)
```
