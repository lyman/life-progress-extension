# Прогресс жизни · life-progress

Расширение для браузера (страница новой вкладки / всплывающее окно на панели), которое всегда держит индикатор прогресса вашей жизни перед глазами.

Настройки по умолчанию: дата рождения **1980-02-20** · ожидаемая продолжительность жизни **30 000 дней** (≈ 82,1 года · до 2062-04-10) — изменяйте в любой момент через **⚙** в правом верхнем углу страницы.

## Расширение для браузера (Edge / Chrome и другие Chromium · v1.3.3)

Код находится в `extension/` и имеет три точки входа:

| Точка входа | Примечания |
|---|---|
| Новая вкладка | Индикатор на всю страницу + строка поиска. **Не работает в Vivaldi**: Vivaldi не позволяет расширениям перехватывать новую вкладку (использует собственную стартовую страницу) |
| Окно на панели | Клик по значку на панели показывает прогресс — работает во всех браузерах (пользователям Vivaldi: используйте это) |
| Горячая клавиша | `Alt+Shift+L` открывает окно (меняется в Расширения → Сочетания клавиш) |

Установка: откройте `edge://extensions` (Chrome: `chrome://extensions`, Vivaldi: `vivaldi://extensions`) →
включите **режим разработчика** → **Загрузить распакованное расширение** → выберите папку `extension/`.
**После обновления кода нажмите «Обновить» на этой странице** (изменения manifest всегда требуют перезагрузки) и закрепите значок на панели.

- Изменить настройки: **⚙** в правом верхнем углу страницы — дата рождения / продолжительность жизни, применяется мгновенно и общая для новой вкладки и окна (хранится в `chrome.storage`, синхронизируется между устройствами с одним аккаунтом); значения по умолчанию — в начале `extension/life-core.js`
- Строка поиска: ищет через поисковик браузера по умолчанию (`chrome.search`); если API недоступен (например, страница открыта как обычный файл), форма отправляет запрос в Bing — запасной вариант меняется через `action` у `<form>` и `name` у `<input>` в `extension/newtab.html`
- Светлая и тёмная темы следуют за системой автоматически
- Языки: 19 языков в `extension/_locales/` следуют за языком браузера (при отсутствии совпадения — английский); добавить язык = добавить папку; формат чисел следует региональным настройкам браузера; языки с письмом справа налево (например, арабский) автоматически зеркалят интерфейс
- Перегенерировать значки: `python3 tools/make_icons.py` (синий скруглённый квадрат + белая полоса 57%, вывод в `extension/icons/`)

## Структура проекта

```
life-progress/
├── extension/           # само расширение (для «Загрузить распакованное» выберите эту папку)
│   ├── manifest.json    # манифест MV3 (разрешение storage, горячие клавиши)
│   ├── newtab.html/js   # новая вкладка: полоса на всю страницу + поиск
│   ├── popup.html/js    # окно на панели: компактная полоса
│   ├── life-core.js     # единственный источник логики: конфиг по умолчанию + расчёт + чтение/запись chrome.storage
│   ├── i18n.js          # точка входа msg() + подстановка статического текста + направление RTL
│   ├── settings.js      # ⚙ панель настроек (общая для обеих страниц, внедряемая)
│   ├── _locales/        # 19 языковых пакетов; следуют языку браузера, резерв — en
│   └── icons/           # значки всех размеров (создаются tools/make_icons.py)
└── tools/
    └── make_icons.py    # генератор значков (только стандартная библиотека; поменяйте PCT/BG и запустите снова)
```
