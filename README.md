# Life Progress · life-progress

A browser extension (new tab page / toolbar popup) that keeps your life progress bar in view.

Default config: birthday **1980-02-20** · life expectancy **30,000 days** (≈ 82.1 years · ends 2062-04-10) — change it anytime via **⚙** in the top-right corner of the page.

## Browser extension (Edge / Chrome and other Chromium browsers · v1.3.2)

The code lives in `extension/`, with three entry points:

| Entry point | Notes |
|---|---|
| New tab page | Full-page progress bar + search box. **Does not work in Vivaldi**: Vivaldi doesn't let extensions take over the new tab page (it uses its own start page) |
| Toolbar popup | Click the toolbar icon to see the progress — works in every browser (Vivaldi users: use this one) |
| Keyboard shortcut | `Alt+Shift+L` opens the popup (changeable under Extensions → Keyboard shortcuts) |

Install: open `edge://extensions` (Chrome: `chrome://extensions`, Vivaldi: `vivaldi://extensions`) →
enable **Developer mode** → **Load unpacked** → select the `extension/` folder.
**After updating the code, click "Reload" on that page** (manifest changes always require a reload), then pin the icon to the toolbar.

- Change settings: **⚙** in the top-right corner of the page — birthday / life expectancy, applied instantly, shared by the new tab page and the popup (stored in `chrome.storage`, synced across devices signed in to the same account); factory defaults live at the top of `extension/life-core.js`
- Search box: uses the browser's default search engine (`chrome.search`); if the API is unavailable (e.g. the page is opened as a plain file), the form falls back to Bing — to change that fallback, edit the `action` of the `<form>` and the `name` of the `<input>` in `extension/newtab.html`
- Light and dark themes follow the system automatically
- Languages: 19 locales in `extension/_locales/` follow the browser language (fallback: English); adding a language = adding a folder; number formatting follows the browser locale; RTL languages (e.g. Arabic) mirror the layout automatically
- Regenerate icons: `python3 tools/make_icons.py` (blue rounded square + white 57% progress bar, output to `extension/icons/`)

## Project structure

```
life-progress/
├── extension/           # the extension itself (select this folder for "Load unpacked")
│   ├── manifest.json    # MV3 manifest (storage permission, keyboard shortcut)
│   ├── newtab.html/js   # new tab page: full-page bar + search box
│   ├── popup.html/js    # toolbar popup: compact bar
│   ├── life-core.js     # single source of logic: default config + math + chrome.storage I/O
│   ├── i18n.js          # msg() entry point + static text replacement + RTL direction
│   ├── settings.js      # ⚙ settings panel (shared by both pages, injected)
│   ├── _locales/        # 19 language packs; follow the browser language, fallback en
│   └── icons/           # icons in all sizes (generated by tools/make_icons.py)
└── tools/
    └── make_icons.py    # icon generator (pure stdlib; tweak PCT/BG and re-run)
```
